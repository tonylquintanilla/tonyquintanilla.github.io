About This Exhibit

Keplerian orbits computed from mean orbital elements (J2000 epoch, NASA Planetary Fact Sheets / JPL). Position markers show where each planet is on the selected date, calculated from Kepler's equation.

The orbits are ellipses in the ecliptic plane, tilted by each planet's inclination and rotated by its ascending node and argument of perihelion. This is the idealized two-body solution — the same math Kepler used in 1609.

All computation runs in your browser via Pyodide (Python compiled to WebAssembly). No server, no API calls. The math is yours to inspect.

Part of Paloma's Orrery — named for the inventor's daughter. Data: JPL/NASA. Computation: NumPy via Pyodide.

The frame

The x arrow points at the vernal equinox, the First Point of Aries (♈). The floor of this box is the ecliptic, the plane of Earth's orbit, and z stands up from it. The frame is fixed to the stars at epoch J2000; it does not turn with the page.

Source: NASA/JPL NAIF, Frames and Coordinate Systems tutorial (J2000 x axis at the equator-ecliptic intersection, the vernal equinox; the ecliptic frame shares it): naif.jpl.nasa.gov. The renderer rotates every pole into this frame (feature_renderers.js, poleBasis).
